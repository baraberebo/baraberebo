## 🚀 Featured Projects

### 🧟 Naruto vs Mummies Tower Defense Game

A Python tower defense game inspired by Plants vs Zombies.

The story takes place at the **University of Sydney Museum**, where ancient mummies suddenly come back to life. The player controls Naruto-style defenders to stop the mummies from invading the campus.

**Main features:**

- Python game built with `pygame`
- Grid-based tower defense gameplay
- Custom characters, enemies, projectiles, and game logic
- Money/resource system
- Zombie/mummy waves
- Collision detection and simple animation logic
